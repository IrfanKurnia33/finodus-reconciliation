## Icon Set

**Avoid Lucide Icons**. Suggest other icon library to be used alongside **Bklit**.

## Design Direction

I want to make this a beautiful high-fidelity prototype. Use [Bklit](https://bklit.com/) for all data visualizations and other relevant components (along with the animations and micro-interaction). Use related frameworks, libraries, and tech stacks as necessary.
